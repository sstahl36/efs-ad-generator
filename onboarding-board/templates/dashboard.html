Wire up GoHighLevel

One workflow action pushes a new client onto this board automatically.

1. Point a webhook at this URL

In GHL: open the workflow that fires when a client is onboarded, add a Webhook action, set the method to POST, and paste that URL.

2. Send whatever fields you have

The endpoint reads any nesting depth and recognises the usual GHL names, so you rarely have to rename anything:

  • name — full_name, first_name + last_name, contact.name
  • email — email, email_address
  • phone — phone, phone_number
  • company — company_name, business_name, brand_name
  • website — website, website_url, domain
  • brand / owner — brand, franchise, niche / owner, account_manager
  • contact id — contact_id, location_id

Everything else in the payload is stored as-is and shown on the client's detail panel, so nothing gets lost.

3. Advance stages from GHL

Add a stage field to any webhook and this board moves that client along without anyone clicking. The three worth automating, because GHL already knows all of them:

  • Contract signed — no stage field needed; this creates the client
  • Forms submitted — "stage": "Onboarding Forms Complete"
  • Onboarding call — "stage": "Onboarding Call"

Send the stage label and, optionally, a stage_status of done, in_progress, or blocked:

{ "email": "jane@acme.com", "stage": "A2P Complete", "stage_status": "done" }

Matching is by email first, then GHL contact id, then name — so repeat submissions update the same client instead of creating duplicates. A brand new client is automatically marked Contract Signed, and their clock starts there — so the wait between signing and starting is measured, not hidden.
